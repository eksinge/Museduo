# Museduo 0.1.3 验证 / Verification

本次发布更新名称和中英文介绍；账号绑定逻辑及资料路径保持不变。
This release updates the name and bilingual descriptions while preserving account bindings and profile paths.

- `npm test`：7/7 项检查通过。All seven unit checks passed.
- `npm run test:e2e`：使用较短的源码路径复验，六项真实 Chrome 隔离与持久化检查通过，涵盖 Cookie、localStorage、IndexedDB、重开和切换工作目录。All six real-Chrome isolation and persistence assertions passed from a shorter checkout path.
- Codex CLI 安装返回版本 `0.1.3`；安装缓存中的插件显示名为 `Museduo`，技能名为 `museduo`。Codex CLI installed version `0.1.3`; installed manifests and skill metadata use the new name.
- 当前真实对话的 `info` 调用成功，原有 `CodexMuse` 资料路径不变。A read-only `info` call succeeded for the real current conversation; the existing profile location is unchanged.

Windows 路径说明：在过长的源码路径下运行浏览器测试，IndexedDB 打开曾出现 backing-store 错误；同一份源码复制到较短路径后测试通过。若复现，请缩短检出目录再运行浏览器测试。Windows path note: the first browser-test run encountered an IndexedDB backing-store error under a long checkout path. The same source passed from a shorter checkout. Use a shorter path if this occurs.

未替用户登录两个真实 Muse 账号；测试使用临时目录和虚构身份，不涉及现有登录资料。Tests used temporary profiles and synthetic identities, not real Muse accounts or existing login data.
